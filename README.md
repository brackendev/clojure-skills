# Clojure Skills

Clojure and ClojureDart skills for Claude Code and Codex.

## Packages

- `clojure`: idiomatic Clojure guidance, project scaffolding, and quality checks.
- `clojuredart`: ClojureDart syntax and interop guidance, Flutter project scaffolding, quality checks, testing, and upgrades.

## Choose Your Platform

- [Claude README](./claude/README.md)
  Install, update, and use these skills in Claude Code with either APM or the native Claude marketplace.
- [Codex README](./codex/README.md)
  Install, update, and use these skills in Codex with APM.

## Included Skills

`clojure` includes:

- `clj-new`
- `clj-check`
- `clojure`
- `clojure-lenses`

`clojuredart` includes:

- `cljd-new`
- `cljd-check`
- `cljd-upgrade`
- `cljd-test`
- `cljd-nav`
- `clojuredart`
- `clojuredart-lenses`

## Requirements

- `clojure` requires [Clojure CLI](https://clojure.org/guides/install_clojure) and [clj-kondo](https://github.com/clj-kondo/clj-kondo).
- `clojuredart` requires [Clojure CLI](https://clojure.org/guides/install_clojure), [clj-kondo](https://github.com/clj-kondo/clj-kondo), [Flutter SDK](https://docs.flutter.dev/get-started/install), and [ClojureDart](https://github.com/Tensegritics/ClojureDart).
